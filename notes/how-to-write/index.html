新建一篇笔记#

在 src/content/notes/ 下新建一个 .md 文件，文件名就是网址。例如 linux-tips.md 会出现在 /notes/linux-tips/。

文件开头写上 frontmatter：

---
title: 文章标题            # 必填
description: 一句话摘要     # 可选，用于列表和搜索结果
date: 2026-11-09           # 必填，发布日期
updated: 2026-11-20        # 可选，更新日期
tags: [Linux, 工具]         # 可选，会自动生成标签页
draft: true                # 可选，草稿只在本地 npm run dev 时可见
toc: false                 # 可选，关闭文章目录
---

如果需要在文章里使用组件，把扩展名改成 .mdx。

常用写法#

代码#

行内代码写成 npm run dev，代码块会自动高亮，并且跟随亮 / 暗色主题：

def fib(n: int) -> int:
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

表格#

命令 作用
npm run dev 本地开发，修改后自动刷新
npm run build 类型检查、构建并生成搜索索引
npm run preview 预览构建结果（可以测试搜索）

图片#

把图片放在 public/images/ 下，然后这样引用：

![说明文字](/images/example.png)

站内链接也直接写绝对路径，例如 全部标签。网站部署在子路径（比如 /lihango/）时，构建过程会自动补上前缀，写文章时不用管。

发布#

修改完成后提交并推送到 GitHub，网站会自动重新构建、发布。
